# WorkLog — 作業時間トラッカー

タスクごとの作業時間を記録して、グラフで振り返るためのタイマーアプリです。
ブラウザだけで動き、PC にアプリとしてインストールすることもできます（PWA）。サーバーやアカウントは不要です。

## 機能

- **3 つのタイマー**
  - ストップウォッチ（カウントアップ）
  - カウントダウン（5〜90 分のプリセット、または任意の分数）
  - ポモドーロ（作業 25 分 / 短い休憩 5 分 / 4 回ごとに長い休憩 15 分。時間は設定で変更可）
- **タスク管理**：「作業」「日常」の 2 カテゴリ。色分け、名前変更、アーカイブ（記録は残して一覧から隠す）
- **記録と集計**：今日 / 7 日間 / 30 日間 / 全期間で集計
  - タスク別の合計（横棒グラフ）、日別の推移（タスク別の積み上げ棒グラフ）
  - 記録一覧から時間・メモを編集・削除できる
  - 計り忘れた分は「手動で記録を追加」から登録できる
- **終了の知らせ**：音とデスクトップ通知
- **中断に強い**：ブラウザを閉じたり再読み込みしたりしても、タイマーは続きから再開します
- **バックアップ**：JSON の書き出しと読み込み、CSV の書き出し（Excel で開けます）
- ショートカット：タイマー画面で `Space` を押すと開始 / 一時停止

## 使い方

### いちばん手軽な方法

`index.html` をブラウザで開くだけで使えます。

### PC にアプリとしてインストールする（おすすめ）

インストールには `http(s)://` で配信する必要があります。

**GitHub Pages で公開する場合**

1. GitHub のリポジトリで **Settings → Pages** を開く
2. Source に「Deploy from a branch」を選び、このファイルがあるブランチと `/ (root)` を選んで保存
3. 表示された URL（`https://<ユーザー名>.github.io/timer/`）を Chrome か Edge で開く
4. アドレスバー右側の「インストール」アイコン（またはメニュー →「アプリをインストール」）をクリック

インストールすると、スタートメニューやデスクトップから独立したウィンドウで起動できます。オフラインでも動きます。

**ローカルで動かす場合**

```bash
python3 -m http.server 8000
```

上のコマンドを実行してから `http://localhost:8000` を開き、同じようにインストールします。

## データについて

- 記録はブラウザの localStorage に保存され、外部には送信されません。
- 保存先はブラウザごと（URL ごと）に分かれます。`index.html` を直接開いた場合と GitHub Pages の URL で開いた場合では、データは共有されません。
- ブラウザのデータを消すと記録も消えるので、ときどき「設定 → JSONで書き出し」でバックアップしてください。

## 注意

- ブラウザは、裏に回したタブのタイマー処理を間引きます。そのためカウントダウンやポモドーロの終了通知が、最大 1 分ほど遅れることがあります。記録される時間は正確です。
- 通知を出すには「設定 → デスクトップ通知」をオンにして、ブラウザの通知を許可してください。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面 |
| `style.css` | 見た目（ライト / ダークモード対応） |
| `app.js` | タイマー・記録・グラフなどすべての処理 |
| `sw.js` | オフライン用のキャッシュ（Service Worker） |
| `manifest.webmanifest`, `icons/` | アプリとしてインストールするための情報とアイコン |
