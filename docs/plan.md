## データ構造の追加（要件書 9 章に対して）

- `Session.completed: boolean`：ポモドーロを最後まで終えたか。途中で止めて「記録する」を選んだものは `false`。完了ポモドーロ数と実績/見積もりはこれで数える。
- `ActiveTimer.phaseDurationSec: number`：実行中のフェーズの長さ。タイマー中に設定を変えても、実行中の回は変わらない。
- `ActiveTimer.lastCheckAt: string | null`：ストップウォッチの止め忘れ確認を最後に出した時刻。

## 決定事項

- カウントダウンは作らない（ポモドーロとストップウォッチの 2 モード）。
- 途中で止めたポモドーロを「記録する」場合：種別はポモドーロで保存し、完了数には数えない。
- アプリを閉じている間に作業が終わった場合：次に開いたとき本来の終了時刻で記録する。連続モードでも、その次の作業は自動で始めない。
- ストップウォッチの止め忘れ確認：「続ける / 確認した時点で止めて記録 / 今止めて記録」の 3 択。
- 終了時のメモ欄は画面内に出すだけで、タイマーは止めない。
- 日付の区切り時刻は日・週・月のすべての集計に使う。
- JSON の統合読み込みでは、設定は今の端末のものを残し、実行中のタイマーは読み込まない。
- アラーム音は音源ファイルを使わず Web Audio で生成し、2〜3 種類から選べるようにする。
- iPhone・iPad の Safari で開いたときは「ホーム画面に追加」を案内する（閉じると再表示しない）。
